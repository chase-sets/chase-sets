# Experience Domain Glossary

## Platform Feedback

**Platform Feedback** is an internal record of a user's experience with Chase Sets.

Notes:

- Platform Feedback evaluates the platform, not another account.
- Platform Feedback is visible to internal users only.
- Platform Feedback contains a Rating, Topic, optional Comment, source workflow, and source context.

## Rating

A **Rating** is the numeric experience score inside Platform Feedback.

Notes:

- Ratings are integer values from `1` through `5`.

## Topic

A **Topic** is the required high-level area the feedback is about.

Examples:

- Ease of use
- Pricing/fees
- Product data/search
- Checkout/payment
- Selling/inventory
- Performance/reliability
- Other

## Comment

A **Comment** is the optional written narrative attached to Platform Feedback.

## Source Workflow

A **Source Workflow** identifies the user task that produced a feedback prompt.

Examples:

- Checkout payment
- Listing publish
- Offer submit
- Offer accept
- Inventory create
- Inventory adjust

## Prompt Dismissal

A **Prompt Dismissal** records that a user chose not to leave feedback for a Source Workflow at that time.

## Review Queue Status

**Review Queue Status** is the internal lifecycle state for Platform Feedback.

Examples:

- New
- Reviewed
- Archived
