`shell-support` provides cross-slice shell composition modules for Identity web surfaces, including shared page registries and API client hooks consumed by multiple slices; this folder is the integration seam between slice UI modules and deployable shells. For example, `ui/admin-pages.tsx` aggregates admin pages from several slices, while `api/client.ts` and `ui/use-fetch.ts` provide common shell data-fetch wiring used by the shell layer.
