`read-model-support` defines cross-slice read-model and projection utilities for Identity slices that project streams into SQL tables and expose paginated list queries; the contract is intentionally narrow: helpers must stay persistence-focused, side-effect free beyond database I/O, and generic enough to be reused by at least two slices. For example, `extract-id-from-stream.ts` normalizes stream-id parsing for projection handlers across accounts/users/memberships, and `list-query.ts` provides the standard filtered list-query builder/executor used by multiple slice query modules.
