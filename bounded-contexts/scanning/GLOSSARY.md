# Scanning Glossary

- **Scan Session**: account-owned lifecycle that records bounded captures and the seller's confirmation outcome.
- **Card Scan**: one opaque capture reference within a session; image bytes are outside this context.
- **Identification Candidate**: advisory provider-independent candidate, never a Catalog identity authority.
- **Confirmed Match**: seller-confirmed complete Catalog Product descriptor and selected options.
- **assetRef**: bounded opaque reference to a capture, with no URL, bytes, EXIF, GPS, or provider payload.
