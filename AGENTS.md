This is a greenfield project. Breaking changes are okay. Code is scalable, maintainable, follow domain driven design principles, prioritize clarity and simplicity, use vertical slicings, favor single responsibility, composition over inheritance, functional patterns and be self-explanatory. The design system is the canonical source of truth for all UI components and patterns with no custom overrides. The marketplace is designed to scale and accommodate a wide range of buyers and sellers, with a focus on competitive pricing, efficient workflows, and better margins for low-value cards. Terms use natural language and match both internal and external uses.
