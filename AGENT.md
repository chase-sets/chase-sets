This is a greenfield project. Breaking changes are okay. The only requirement is code should be clean and maintainable. Favor single responsibility, composition over inheritance, and functional patterns. Code should be self-explanatory. Use TypeScript for type safety and React for the UI layer. Use Tailwind CSS for styling and Radix UI for primitives. The design system should be the canonical source of truth for all UI components and patterns. The marketplace should be designed to scale and accommodate a wide range of buyers and sellers, with a focus on competitive pricing, efficient workflows, and better margins for low-value cards. Terms should default to natural language and match both internal and external uses.
