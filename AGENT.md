This codebase is a greenfield project. Make changes sweeping changes as you see fit. The only requirement is that the code should be clean and maintainable. Favor single responsibility, composition over inheritance, functional patterns and avoid over-engineering. The code should be self-explanatory and well-documented. Use TypeScript for type safety and React for the UI layer. Use Tailwind CSS for styling and Radix UI for primitives. The design system should be the canonical source of truth for all UI components and patterns. The marketplace should be designed to scale and accommodate a wide range of buyers and sellers, with a focus on competitive pricing, efficient workflows, and better margins for low-value cards.
